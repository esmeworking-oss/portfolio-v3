# Esme Chang — Product Designer Portfolio

https://portfolio-v3-black-zeta.vercel.app

Personal portfolio of Esme Chang, a product designer working on membership systems and healthcare products (中文 / English / 日本語).

Designed and built solo in two weeks with an AI-assisted workflow — the process is documented in the [AI Collaboration in Practice](https://portfolio-v3-black-zeta.vercel.app/en/projects/ai-workflow) case study.

## Case studies

- Symptomtrace (松鼠醫生) App & Dashboard
- Burger King 豪點王 Redesign
- TSG Membership System
- WINGSTARS Cheerleading Official Website
- AI Collaboration in Practice

## Stack

[Astro](https://astro.build) 6 · Tailwind CSS 4 · Astro i18n (`zh` default, `/en/`) · deployed on Vercel

## Development

```sh
npm install
npm run dev      # http://localhost:4321
npm run build    # output in ./dist
```

Design tokens and layout rules live in [`docs/design-system.md`](docs/design-system.md); English proper nouns in [`src/i18n/PROPER_NOUNS.md`](src/i18n/PROPER_NOUNS.md).
